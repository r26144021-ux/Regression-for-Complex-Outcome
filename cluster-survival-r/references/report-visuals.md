# 分析報告的摘要、選模理由與補充圖表

## 所有模型
報告頂部提供精簡重點摘要：研究問題、資料／樣本單位、為何選這一模型、主要效果與區間、實際診斷判斷。摘要數值必須來自同一資料與設定的 R 輸出；可用 inline R 動態填入。先簡介結果再展開完整 code 與細節，避免把摘要變成另一份長報告。

選模理由連結到結果尺度（時間／連續／二元等）、設限／重複測量／群集結構與估計目標，不只寫「因為結果是二元」。本 Skill 不為增加圖表或摘要改變研究目的、加入未確認共變數或配適範圍外主模型。

## Cox
- 可以加分組 KM 曲線、合理時間點的存活估計表與 At-risk table，與 Cox 模型估計曲線清楚區分。KM 是本次存活資料的描述性補充；不因加圖另改主分析。
- At-risk 定義與時間單位需說明，避免將最後觀測後的存活估計無限制外推；各時點仍在追蹤的人數須由實際資料或 survfit 計算。
- HR 森林圖用 log 刻度、95% CI 與 HR=1 參考線，標示比較組／單位；只有一個效果也可示範，但不為圖表而增加變數。
- 若研究目標含區辨／預測評估或使用者要求，可報 concordance(fit) 的 Harrell C，Cox 方向交由該方法正確處理。說明 time weighting、分析樣本、表觀或已驗證結果。C-index 是風險排序區辨，不是校準、個人預測正確率或證明預測能力；不得把訓練資料 C 當外部驗證，亦不因 C 高／低直接判斷整個關聯模型是否有效。驗證需另有資料／重抽樣規劃。

## GEE
- 依結果尺度選圖。二元結果且個體很多時，逐一 Spaghetti plot 常重疊而不易解讀；可優先呈現觀察比例與邊際預測機率圖。
- 使用係數估計及 robust 協方差，在 link 尺度產生逐點 CI 再轉回結果尺度，清楚說明條件設定或如何對其他共變數標準化。不是個體隨機預測，不把逐點 CI 當同時帶、也不以兩組 CI 重疊取代正式組間檢定。
- 若模型尚未做適用的小樣本修正而獨立群很少，圖中也不得偷用普通 san.se 畫出看似正式的推論區間；只給探索性點估計或採已驗證修正。

## LMM
- 以可離線閱讀的數學排版列固定效果、隨機效果、誤差與層級；與實際 R formula 一致。
- 變異數／SD 與截距—斜率的共變異／相關分開列，避免原始 VarCorr 長表的結構性 NA 讓讀者誤認資料缺失。相關列沒有一個可解釋為單一變異的 SD；勿混列或補 0。
- 只有隨機截距時，ICC = sigma_b^2/(sigma_b^2+sigma_e^2) 可作條件變異占比；說明模型是否含共變數及尺度。
- 有隨機斜率時，V_b(t)=G00+2*t*G01+t^2*G11；優先報具意義天數的 VPC(t)=V_b(t)/(V_b(t)+sigma_e^2)，例如基準日與後續訪視。單一基準日 ICC 不能當全時程共用 ICC；不同兩時點的相關須用相應的共變異及總變異計算。
- GLMM 的 ICC 另涉及連結／結果尺度與分布特有變異，不直接搬用 Gaussian 殘差公式。不要為了輸出簡單 ICC 而默默刪掉隨機斜率。

## 表格 NA
先區分結構性「不適用」、未估計與真正失敗／缺失。VarCorr 的 var2 在單一變異列為 NA、殘差沒有隨機參數名稱，屬結構性不適用；模型比較的第一個基準列沒有與前一模型的差異檢定，亦正常。可改列友善表格，或以「—」並註明原因。估計、SE 或應有檢定因失敗而變成 NA 時，須追查，不一律改為「—」掩蓋。
