# 建模前資料探索（EDA）

收到資料與目的後、提出模型建議前使用。EDA 用來了解資料並支援設定，不是用顯著性自動選模，也不取代建模後診斷。已完成且仍適用的檢查不用重做；目的或關鍵語意不明時先做不依賴該資訊的摘要，再集中澄清。

## 每次的基本檢查
- 核對欄位、型別、單位、編碼、範例值、列數及每列意義；依研究問題整理變數角色。
- 分析欄位的缺失數／比例、數值範圍及非有限值、類別頻數；標示不合理值或疑似輸入錯誤，確認後才處理。
- 群集／重複測量資料檢查獨立群數、群大小分布、每群測量次數、訪視間距及重複 id-time；事件時間資料檢查追蹤時間與事件／設限數。
- 保留原資料，記錄轉換及排除原因、原始與分析列數／群數。不預設插補、刪離群值或為改善圖形而轉換變數。

## 依問題選擇摘要與圖表
只選能支援本次研究目的或模型設定的項目，不要求所有數值變數兩兩作圖。資料量大時選分組摘要、適當抽樣的個體軌跡（交代抽樣方式）或其他可讀呈現。

| 資料／候選模型 | 可選探索 | 要回答的問題 |
|---|---|---|
| 事件時間／Cox | 追蹤時間摘要、事件與設限比例、主要組別 KM 曲線及風險人數 | 追蹤是否充足？組間存活走勢如何？後段是否資料稀少？KM 是未調整描述，不替代 PH 診斷或調整後 HR |
| 連續重複測量／LMM | 結果分布、時間點摘要、個體軌跡、組別平均趨勢 | 時間趨勢如何？個體基準與變化是否不同？原始結果不常態不能直接否決 LMM |
| 二元／計數群集資料／GLMM 或 GEE | 各時間與主要組別事件比例／平均計數及分母、群大小；需要時檢查曝險期間、零值頻率 | 是否有稀少事件、不均衡群或不同曝險時間？原始零值多不能單憑此認定零膨脹 |
| 有特定成長／衰減機制／NLMM | 觀察軌跡、時間涵蓋與合理參數範圍 | 是否有支持特定曲線與參數估計的資料？看似彎曲不代表必須 NLMM |

完成後簡述「發現 → 對後續分析的影響」；例如晚期測量少，對晚期估計要保留不確定性。圖形只能提示設定，不能靠圖自動指定隨機斜率或改變研究目標。需變更已確認的分析方案時先說明；資訊已清楚且已授權的摘要與圖表不逐項詢問。

## 對話與報告
對話先交代重要發現，再提出模型與設定。QMD／HTML 保留與選模、資料處理或結果解釋相關的探索及程式，省略無關探索；同資料同設定的數值應一致，文字、圖表組合與版面可彈性調整。未執行的探索不能寫成已完成。
